One dated line per decision that changes the design. Newest at the bottom.

- 2026-10-29: Bumped `@types/node` to `^22` (matches the Node 22 runtime; Vitest 5 requires `^22 || >=24`, and npm refuses to install with `^20`).
- 2026-10-31: Task 0.5 embedding decision: `gemini-embedding-2` at 768 dimensions (`vector(768)` stays), with no additional L2 normalization (768-dimension vectors measured unit length; Google documents automatic normalization for reduced dimensions). The adapter applies the document prefix `title: none | text: {text}` at ingest and the query prefix `task: search result | query: {text}` at search time (no `taskType`), and the exact model id is stored per chunk in `chunks.embedding_model`. Evidence: `docs/spikes/provider.md` section 5.6 (USER-verified, not independently file-inspected). Not decided here: quota accounting (and the quota behind the unpaced-run 429s) and real-PDF ingest time.

If it becomes a real product, reassess paid-tier privacy and data-handling requirements. LLM roles remain provisional: Gemini primary, Groq fallback.
