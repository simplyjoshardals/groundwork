# Sample document facts (Task 0.9)

Ground truth for the two public sample documents of the fictional company Kestrel & Vane Ltd. Slice 2 mines this file for eval questions. Both documents live in `supabase/seed/`:

- `kestrel-vane-employee-handbook.pdf` (10 pages, generated by `build_sample_pdf.py`)
- `kestrel-vane-faq.md` (12 questions)

`tests/unit/sample-docs.test.ts` checks every table below against the real files. If you edit a document, run `yarn test`, and never renumber an ID (eval questions will refer to it).

How to read it:

- **Page** is the physical PDF page, which is also the number printed in the page footer.
- **Quote** is exact text from that page (line breaks count as spaces). It appears exactly once in the whole PDF, so it is safe to use as the expected passage.
- **two-paragraph** means the answer needs two consecutive paragraphs on the same page, and the two quotes are separated by `//`. Facts never cross a page boundary, because the chunker never does.
- The FAQ is Markdown, so it has no real pages. FAQ facts are referred to by question number (Q1 to Q12).
